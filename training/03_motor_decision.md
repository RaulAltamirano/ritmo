# WFITNESS: Motor de decisión (programa + progresión)

**Propósito:** Elegir plantilla base y reglas de progresión/deload.  
**Entrada:** perfil de [`00_instrucciones_ia.md`](00_instrucciones_ia.md).  
**Salida:** nombre de programa + archivo `02A`/`02B`/`02C` + reglas de las próximas semanas.

---

## 1. Clasificar nivel (si no viene dado)

| Nivel | Criterio orientativo |
| :--- | :--- |
| **Básico** | &lt; 6–8 meses de entrenamiento serio, o técnica inestable en squat/hinge/press |
| **Intermedio** | 6–24 meses consistentes, cumple reps en RIR 1–3 la mayoría de series |
| **Avanzado** | &gt; ~2 años, maneja técnicas (rampa, drop, rest-pause, gigantes) sin romper forma |

Si hay duda entre dos niveles → **elige el inferior**.

---

## 2. Árbol: nivel × días → programa base

Usa la **menor frecuencia ≥ días disponibles** solo si el cliente puede cumplirla; si pide exactamente N días, elige fila N.

### Básico → [`02A_rutinas_basicas.md`](02A_rutinas_basicas.md)

| Días/sem | Programa |
| :---: | :--- |
| 3 | No hay plantilla 3d: usar **Intermedio 1.0** solo si el coach confirma “básico fuerte”; si no, **Básico 1.0** en 3 de 4 días (rotar descanso) y avisar |
| 4 | **Básico 1.0** |
| 5 | **Básico 2.0** (default) o **Básico 3.0** si ya dominó 2.0 / pide más variedad de rampas |
| 6 | **Básico 2.0** o **3.0** + 1 día técnico ligero (RIR 3–4) o descanso; no saltar a avanzado |

### Intermedio → [`02B_rutinas_intermedias.md`](02B_rutinas_intermedias.md)

| Días/sem | Programa |
| :---: | :--- |
| 3 | **Intermedio 1.0** (default) · **1.2** si prefiere upper emphasis · **1.3** si prefiere más pierna / glúteo |
| 4 | **Intermedio 2.0** |
| 5–6 | **Intermedio 2.0** + opcional día extra de debilidad (solo aislamientos, RIR 2–3) **o** subir a Avanzado 2.x si el nivel real es avanzado |

### Avanzado → [`02C_rutinas_avanzadas.md`](02C_rutinas_avanzadas.md)

| Días/sem | Programa (default → alternativas) |
| :---: | :--- |
| 3 | No ideal: **Intermedio 1.x** con RIR estricto, o Avanzado condensado solo con OK del coach |
| 4 | **1.1** Pesado/Ligero (default) · **1.2** Series gigantes si tolera densidad |
| 5 | **1.3** Weider · **2.1** / **2.2** · **3.1** (más intensificadores) |
| 6 | **3.2** Rest pause |

**Matiz de objetivo**
- Prioriza hipertrofia general + adherencia → defaults de la tabla.
- Quiere máxima fatiga metabólica y ya es avanzado → 1.2 / 3.1 / 3.2.
- Quiere estructura simple y fuerza-hipertrofia → 1.1.

**Equipo / tiempo**
- Sesión &lt; 45 min: preferir plantillas con menos bloques; no cambiar de nivel solo por tiempo.
- Equipo incompleto: mantener programa; sustituir con [`04_catalogo_ejercicios.md`](04_catalogo_ejercicios.md).

**STOP lesiones:** no elijas “programa más fácil” como tratamiento. Remite ([`00`](00_instrucciones_ia.md)).

---

## 3. Progresión (acumulación)

Horizonte típico: **bloques de 4–6 semanas** en la misma plantilla.

| Señal | Acción |
| :--- | :--- |
| Cumple todas las reps objetivo en **RIR 1–3** durante **1–2 sesiones** seguidas en un ejercicio | Subir carga (mínimo step del gym: ~2.5–5 kg compuestos, ~1–2.5 kg aislados) |
| Cumple reps pero con RIR 0 / fallo técnico | Bajar carga 5–10% o dejar 1–2 reps en la próxima |
| No cumple reps con RIR ≤ 3 | Mantener carga; mejorar técnica; no sumar series aún |
| Estancamiento 2–3 semanas en varios lifts | Revisar sueño/estrés; luego +1 serie en 1–2 movimientos prioritarios **o** cambiar a la siguiente plantilla del mismo nivel |

**Nivel básico:** priorizar subir carga en compuestos; evitar drops/rest-pause.
**Intermedio:** rampas/drops solo como en la plantilla.
**Avanzado:** intensificadores solo donde la plantilla los escribe.

---

## 4. Descarga (deload)

| Cuándo | Cómo |
| :--- | :--- |
| Cada **4–6 semanas** de acumulación, o si hay fatiga persistente / sueño malo / RIR inflado | **1 semana** de descarga |
| Durante deload | Mismos días y ejercicios; **~50–70%** de series efectivas **o** mismas series con **RIR 3–4** y sin drops/rest-pause/gigantes |
| Post-deload | Volver a cargas pre-deload o + un step si la técnica fue fácil |

No programes deload la semana 1 de un cliente nuevo salvo fatiga evidente.
