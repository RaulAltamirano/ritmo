## Autoría / salvedad

El framing de bloques + fitness–fatiga en WFITNESS proviene del coach metodológico (nutriólogo; no entrenador de oficio a tiempo completo). Las preferencias de secuenciación se documentan como **Preferencia WFITNESS**; los modelos y citas se contrastan con literatura.
