# Task ↔ Plan Relation (API) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist first-class `Plan` entities with optional `Task.planId`, expose CRUD + cascade soft-delete under `/plans`, and extend task create/update/list with optional `planId`.

**Architecture:** Add `Plan` / `PlanStatus` in Prisma (`business.prisma` + `enums.prisma`), rebuild combined `schema.prisma`, migrate. New `apps/api/src/modules/plans/` (controller → service → Prisma) mirrors `tasks`. Soft-delete of a plan soft-deletes its tasks in one transaction. Progress stats are computed on read. Category stays independent.

**Tech Stack:** Express + TypeScript, Prisma 6 + PostgreSQL, Vitest (DB forks pool), existing `AppException` / `ApiResponses` patterns

**Spec:** `docs/superpowers/specs/2026-08-03-task-plan-relation-design.md`

## Global Constraints

- Slice A only: model + API. Do **not** wire `apps/web` `/planes` or replace the Pinia mock store.
- Canonical name is **Plan** / `/plans` (not Project). Replace orphan `PROJECTS` route constants with `PLANS`.
- `Task.planId` is optional; Plan 1 → N Task; Category independent.
- Soft-delete plan **and** its non-deleted tasks; do **not** mutate `WorkSession` rows.
- Stats: `totalTasks`, `pendingTasks` (`status !== completed`), `progress = floor(100 * completedCount / totalTasks)` or `0` if empty.
- TDD: failing DB test first, then implement. Conventional commits per task.
- ESLint limits: cyclomatic ≤ 10, file ≤ 300 lines, function ≤ 50 lines.
- Edit Prisma modules under `apps/api/prisma/models/`; run `node scripts/build-schema.js` before migrate. Do not hand-edit `schema.prisma` except via that script.

```ts
private async computeStats(planId: string): Promise<PlanStats> {
  const tasks = await prisma.task.findMany({
    where: { planId, isDeleted: false },
    select: { status: true },
  })
  const totalTasks = tasks.length
  const completedCount = tasks.filter(t => t.status === TaskStatus.completed).length
  const pendingTasks = totalTasks - completedCount
  const progress =
    totalTasks === 0 ? 0 : Math.floor((100 * completedCount) / totalTasks)
  return { totalTasks, pendingTasks, progress }
}
```

```ts
await prisma.$transaction(async tx => {
  const plan = await tx.plan.findFirst({
    where: { id: planId, userId, isDeleted: false },
  })
  if (!plan) throw new ResourceNotFoundException('Plan', planId)
  const now = new Date()
  await tx.plan.update({
    where: { id: planId },
    data: { isDeleted: true, deletedAt: now },
  })
  await tx.task.updateMany({
    where: { planId, isDeleted: false },
    data: { isDeleted: true, deletedAt: now },
  })
})
```
